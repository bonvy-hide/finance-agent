## 产品概述

上传原始个股财报 .xls（diy_report 格式）+ 输入公司名，后端实时转换为标准化数据，并基于标准化数据生成 6 个业务图表（趋势/对比/分析），前端沿用现有深色金融仪表盘风格统一渲染。

## 核心功能

### 数据管道

- 上传 .xls 文件 + 输入公司名（前端表单）
- 后端实时解析为标准化数据（13 列），不落地中间文件
- 转换逻辑封装在 `finance/stock_normalize.py`，CLI 和 Web 共用
- `scripts/convert_stock_data.py` 改为薄 CLI 包装

### 6 个业务图表（每张标题含 `{公司}xxx`）

| # | 标题 | 类型 | 数据列 |
| --- | --- | --- | --- |
| 1 | `{公司}总营收与主业现金流增长趋势图` | line 双线 | 滚动总营收 + 滚动现金流 |
| 2 | `{公司}净利润、现金流净额、自由现金流趋势图` | line 三线 | 滚动净利润 + 滚动现金流净额 + 自由现金流FCF |
| 3 | `{公司}成本与毛利率分析` | 柱+折线 双轴 | 左轴：总营收 + 营业成本（柱）/ 右轴：销售毛利率（折线） |
| 4 | `{公司}三费用与业绩对比分析` | 柱+折线 双轴 | 右轴：总营收（柱）/ 左轴：销售费用 + 管理费用 + 研发费用（折线） |
| 5 | `{公司}总营收与应付账款对比` | 柱+折线 双轴 | 左轴：总营收（柱）/ 右轴：应付票据及应付账款（折线） |
| 6 | `{公司}研发费用与净利润趋势图` | line 双线 | 研发费用（单期）+ 净利润（单期） |


### x 轴

按 Excel 季度报告期升序排列（数据起始 OUTPUT_START_YEAR=2016）

### 单位

底层保留元，前端按"亿元"展示（除以 1e8）

### 数据契约

- 上传返回 `{ data_id, periods, columns, rows, company_name }`
- 每张图表返回标准 `ChartResponse`，`chart_type` 新增 `"mixed"` 标识柱+折线双轴
- `extra` 携带图表特有配置：`{ scales: [{position, title}], series: [{type, y_axis, color}] }`

## 技术栈

- 后端：FastAPI + Python 3.12（已有）
- Excel 读取：xlrd 2.0.x（读 .xls）、openpyxl（CLI 写 .xlsx）
- 依赖管理：uv（pyproject.toml）
- 前端：原生 HTML + JS + Chart.js 4.x + chartjs-plugin-datalabels（CDN已有）
- 数据缓存：进程内 `dict[data_id, NormalizedData]`（无 session/Redis，简单可靠）

## 实现方案

### 核心策略

1. **算法层抽取** `finance/stock_normalize.py`：搬迁 scripts/ 下的核心逻辑，扩充 6 个新增科目，毛利率转小数，提供 `normalize(path) -> NormalizedData` 高层接口
2. **数据缓存层** `app/services/data_store.py`：进程内 `dict` 存最近 N份标准化数据（LRU淘汰，默认 100），用 `uuid` 作 `data_id`
3. **图表路由聚合** `app/api/stock_charts.py`：6 个图表路由共用 `chart_type` + `extra` 模式，扩展 `ChartResponse.chart_type` 支持 `"mixed"`
4. **统一上传接口** `app/api/stock_normalize.py`：POST `/api/normalize` 接收 `multipart/form-data`（file + company_name），返回 `data_id`，前端用此 id 调 6 个图表端点
5. **薄 CLI**：`scripts/convert_stock_data.py` 改为调用 `finance.stock_normalize` 的写文件接口

### 关键技术决策

**科目匹配基于名称**：现有 `read_stock_xls` 已按 label 遍历存 dict（顺序无关），仅需扩充 LABEL_MAP 6 项映射

**毛利率百分比转小数**：

- xlrd 读取百分比单元格返回 float（小数形式，如 0.1982），无需转换；但部分模板以字符串 `"19.82%"` 存储，需新增 `_parse_percent`
- 输出统一用0.00% 格式显示

**`'--'` 缺失值**：`_to_float` 已处理字符串返回 None，无须改动

**ChartResponse 扩展 mixed 类型**：

```python
chart_type: Literal["bar", "line", "pie", "doughnut", "mixed"]
extra.series: List[{type: "bar"|"line", y_axis: "left"|"right", ...}]
extra.scales: { left: {title, unit}, right: {title, unit} }
```

**数据缓存策略**：

- 上传时生成 `data_id = uuid4().hex[:12]`，存入 `_store[data_id] = NormalizedData`
- LRU 上限 100，超出淘汰最旧
- 前端持 `data_id` 调 6 个图表端点
- 不做持久化，进程重启即清空**单位转换**：
- 底层 float 全程保留元（精度无损）
- 图表算法输出时按指标自适应单位：金额（元）转 亿元（÷1e8），毛利率保持小数
- `extra.unit = "亿"` 或 `"%"` 告知前端显示

**前端渲染策略**：

- 上传成功后渲染"图表网格"区域，6 张图按顺序渲染
- 每张图独立 `<canvas>` + 独立 Chart 实例，避免相互影响
- mixed 类型图表用 Chart.js 多 dataset + `scales.y.left/right` 配置- 公司名直接拼到 title，前端不再回调后端

### 性能与可靠性

- xlrd 读28KB .xls < 100ms
- 6 张图共用1 份 `NormalizedData`缓存，单请求 O(n)（n=43 报告期），无 N+1
- 临时文件复用 `excel_parser.save_upload` / `cleanup`，用完即删
- 缺失值（'--' 或 None）前端渲染时跳过断点

### 避免技术债

- 复用现有 `ChartResponse` schema，仅扩展字段，不另起炉灶
- 数据缓存复用同一数据结构，不为图表定制存储
- 算法层不依赖 FastAPI，沿用现有约定

## 架构设计

```
用户上传 .xls + 输入公司名
  → POST /api/normalize (multipart)
 → app/services/excel_parser.save_upload (临时 .xls)
  → finance/stock_normalize.normalize(path) → NormalizedData
  → app/services/data_store.put → 返回 data_id
  → cleanup 临时文件
  → 返回 { data_id, periods, columns, rows, company_name }

前端持有 data_id 后并发请求 6 个图表：
  GET /api/charts/revenue-cashflow?data_id=xxx
  GET /api/charts/profit-cashflow-fcf?data_id=xxx
  GET /api/charts/cost-margin?data_id=xxx
  GET /api/charts/three-expenses?data_id=xxx
  GET /api/charts/revenue-payable?data_id=xxx
  GET /api/charts/rd-profit?data_id=xxx

每个图表路由：
  → data_store.get(data_id)
  → finance/stock_charts.<chart>(data) → ChartResponse
  → 返回
```

## 设计风格

沿用现有项目深色金融仪表盘风格（`static/style.css` 中资产负债图风格），不参考效果图配色。背景为深色调，标题加粗白色，6 张图表垂直堆叠于"图表网格"容器，每张图独立卡片。

## 单页布局（自上而下）

1. **顶部刊头**：与现有风格一致，显示日期/期数/状态
2. **上传区**：文件名输入 + 公司名输入 + 选择文件 + 上传按钮
3. **图表网格容器**：6 个独立 canvas卡片，依次渲染## 单图表卡片布局

- 顶部标题（粗体白色，公司名 + 图表名）
- 中部 canvas（Chart.js）
- 底部图例（点击切换显隐）
- 边框/阴影/圆角与现有资产负债图卡片风格统一

## 双轴图表（mixed）

- 左 y 轴：金额（亿元）
- 右 y 轴：金额（亿元）或百分比（毛利率）
- 柱状用蓝/橙色系，折线用对比色（白/红/黄）
- 与效果图配色无关，按项目现有 Chart.js 配色统一

## 交互

- 上传成功后显示所有 6 张图
- 鼠标 hover 显示精确数值
- x 轴标签倾斜45° 避免重叠（与现有风格一致）
- 公司名直接拼到每张图 title
