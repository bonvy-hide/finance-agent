## 产品概述

将个股财报 Excel（`static/template/主要数据.xls`）转换为标准化格式的 xlsx 文件，包含滚动 TTM 业绩、计算科目（归母净资产、自由现金流FCF），按时间升序、指标列固定顺序输出，供后续图表功能使用。

## 核心功能

- 读取 `.xls` 格式个股财报数据（8 个原始科目 + 2 个待计算空科目，43 个报告期列）
- 截取 2015-Q1 到 2026-Q1 的数据范围（2015 年作为滚动计算缓冲年，最终输出从 2016-Q1 起的 10 年完整周期）
- 计算滚动 TTM 业绩：任意报告期往前 4 个季度的累计值（公式：TTM = 本年截至同期累计 - 上年同期累计 + 上年全年累计）
- 计算归母净资产 = 每股净资产 × 实收资本（时点值，非滚动）
- 计算自由现金流 FCF = 经营活动现金流量净额 - 购建固定资产无形资产等支付的现金（单期值，减法标准公式）
- 输出 xlsx：行=时间（升序），列=指标（固定顺序：科目\时间 | 滚动总营收 | 滚动现金流 | 滚动净利润 | 滚动现金流净额 | 归母净资产 | 总营收 | 主业现金流 | 净利润 | 现金流净额 | 自由现金流FCF）

## 技术栈

- Python >= 3.12（项目已有）
- xlrd 2.0.2（已安装，读取 `.xls` OLE2 格式）
- openpyxl（已安装，写入 `.xlsx` 输出文件）
- 无新增依赖

## 实现方案

### 整体策略

编写独立 Python 脚本 `scripts/convert_stock_data.py`，不接入 `app/` 架构，可 CLI 重复运行。脚本内部按职责分函数：读取 → 时间排序 → 截取范围 → 计算科目 → 计算 TTM → 组装输出 → 写入 xlsx。

### 关键技术决策

**1. Excel 读取（xlrd）**

- 用 `xlrd.open_workbook()` 读取 `.xls`，第一个 sheet
- 表头在第 1 行（0-indexed），科目在第 0 列，报告期在第 1~43 列
- 报告期字符串格式 `YYYY-MM-DD`，解析为 `datetime.date` 用于排序和季度判断
- 数值用 `xlrd` 的 `cell_value()` 直接获取（float 或空字符串）

**2. 时间排序与截取**

- 原始数据按时间降序（2026-03-31 → 2013-12-31），需反转为升序
- 截取范围：`date >= 2015-01-01`（保留 2015 全年作为 TTM 缓冲）
- 最终输出范围：`date >= 2016-01-01`（10 年完整周期，2016-Q1 到 2026-Q1）

**3. 滚动 TTM 计算**

- 核心公式：对任一报告期 T，`TTM(T) = YTD(T) - YTD(同年同期的上一年Q1) + FullYear(上一年)`
- 等价实现：按报告期排序后，对每个报告期找到其前 4 个连续季度的单季值求和
- 采用「同年同期 + 上年全年」方法更健壮，因为财报数据本身是累计值
- 对年报（12-31）：TTM = 该年报值本身（全年累计即 TTM）
- 对 Q2（06-30）：TTM = 上半年累计 + 上年下半年（= 上年全年 - 上年上半年）
- 对 Q3（09-30）：TTM = 前三季度累计 + 上年第四季度
- 对 Q1（03-31）：TTM = Q1 + 上年 Q2 + 上年 Q3 + 上年 Q4 = 上年全年 - 上年 Q1 + 当年 Q1
- 需要从 `date` 提取 `year` 和 `quarter`（通过 month 推断：1-3→Q1, 4-6→Q2, 7-9→Q3, 10-12→Q4）

**4. 计算科目**

- 归母净资产 = 每股净资产 × 实收资本（逐报告期计算，时点值）
- FCF = 经营活动现金流量净额 - 购建固定资产...支付的现金（逐报告期计算，单期累计值）

**5. 输出 xlsx 结构**

- 表头行：`科目\时间 | 滚动总营收 | 滚动现金流 | 滚动净利润 | 滚动现金流净额 | 归母净资产 | 总营收 | 主业现金流 | 净利润 | 现金流净额 | 自由现金流FCF`
- 数据行：每行一个报告期（2016-Q1 到 2026-Q1，升序），约 41 行
- 数值保留「元」为单位，不做单位换算
- openpyxl 写入，设置合理的列宽和数字格式

### 性能与可靠性

- 数据量极小（10 行 × 44 列），无性能瓶颈
- TTM 计算需处理缺失数据：若某年某季度数据缺失，该期 TTM 置空而非报错
- 脚本幂等：重复运行覆盖输出文件
- Windows 环境：脚本开头加 `sys.stdout.reconfigure(encoding='utf-8')` 防止中文输出乱码

- `read_stock_xls(path)` → 读取 xls，返回 `{科目名: {date: value}}` 字典 + 报告期列表
- `parse_periods(periods)` → 解析报告期字符串为 date 对象，按升序排列
- `filter_range(periods, start_date)` → 截取指定日期范围
- `compute_derived(data)` → 计算归母净资产、FCF，补充到 data 中
- `compute_ttm(data, periods, label)` → 对指定科目计算每个报告期的 TTM 值
- `build_output_rows(data, periods, output_start)` → 组装输出行（时间升序，指标固定列顺序）
- `write_xlsx(rows, output_path)` → 用 openpyxl 写入 xlsx，含表头和格式
- `main()` → CLI 入口，默认输入 `static/template/主要数据.xls`，默认输出 `outputs/主要数据_标准化.xlsx`，支持 `--input` / `--output` 参数覆盖

# TTM 计算核心逻辑（伪代码签名）
def compute_ttm(values: dict[date, float], periods: list[date]) -> dict[date, float]:
    """
    values: {报告期date: 累计值}，periods: 升序日期列表
    返回: {报告期date: TTM值}
    对每个 T:
      - 年报(12-31): TTM = values[T]
      - Q1(03-31): TTM = values[上年12-31] - values[上年03-31] + values[T]
      - Q2(06-30): TTM = values[T] + (values[上年12-31] - values[上年06-30])
      - Q3(09-30): TTM = values[T] + (values[上年12-31] - values[上年09-30])
    若所需历史数据缺失，该期 TTM = None
    """

# 输出列定义
OUTPUT_COLUMNS = [
